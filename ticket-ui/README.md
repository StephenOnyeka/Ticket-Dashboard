# 🎫 Support Ticket Dashboard — Frontend (ticket-ui)

This directory contains the Next.js 15 frontend application for the Support Ticket Dashboard.

## Quick Start

```bash
# Install dependencies
npm install

# Run dev server on http://localhost:3000
npm run dev

# Run Vitest test suite
npm test
```

Please refer to the main repository [README.md](../README.md) for full project documentation, architecture details, backend setup, and Postman API collection.
